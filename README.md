# cyberlabs-scripts

A collection of macOS scripts and automation tools for Cyberlabs.

## Projects

- **[macos-setup/](macos-setup/)** — Replicate this Mac's setup on another machine
  (Homebrew apps + Finder/Dock/mouse/keyboard preferences) with one command.
- **[Clip2md/](Clip2md/)** — Apple Shortcut that converts the clipboard's rich
  text to a Markdown file.
